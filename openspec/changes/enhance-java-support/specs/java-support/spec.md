## 新增需求
### 需求：Java及JVM语言支持
插件必须支持解析和翻译 Java、Kotlin、Scala 和 Groovy 语言源代码中的注释。

#### 场景：打开Java文件
- **当** 用户打开 `.java` 文件
- **那么** 插件应识别代码中的注释并显示中文翻译

#### 场景：打开Kotlin文件
- **当** 用户打开 `.kt` 文件
- **那么** 插件应识别代码中的注释并显示中文翻译

#### 场景：打开Scala文件
- **当** 用户打开 `.scala` 文件
- **那么** 插件应识别代码中的注释并显示中文翻译

#### 场景：无Java插件环境（如RustRover）
- **当** 用户在没有安装 Java 插件的 IDE（如 RustRover）中打开 `.java` 文件
- **那么** 插件应通过文本回退机制显示中文注释翻译
