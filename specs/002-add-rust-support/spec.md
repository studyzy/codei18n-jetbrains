# 功能规范: Rust 语言注释翻译支持

**功能分支**: `002-add-rust-support`
**创建时间**: 2025-12-17
**状态**: 草稿
**输入**: 用户描述: "现在已经能够对Golang的注释进行替换，我希望增加对Rust语言中注释代码的中英文替换功能"

## 用户场景与测试 *(必填)*

### 用户故事 1 - 翻译 Rust 代码中的英文注释为中文 (优先级: P1)

作为一名使用 IntelliJ IDE 的 Rust 开发者，我希望能够将 Rust 源文件中的英文注释自动翻译成中文，以便我能更快地理解代码逻辑和文档说明。

**优先级原因**: 核心功能需求，帮助非英语母语开发者阅读 Rust 代码。

**独立测试**: 可以通过创建一个包含各种类型英文注释（单行、多行、文档注释）的 `.rs` 文件，运行翻译功能，并验证注释是否被正确替换为中文来测试。

**验收场景**:

1. **给定** 一个包含英文单行注释 `// This is a comment` 的 Rust 文件，**当** 执行“翻译为中文”操作时，**那么** 注释应变为 `// 这是一个注释`。
2. **给定** 一个包含英文文档注释 `/// Documentation` 的 Rust 文件，**当** 执行“翻译为中文”操作时，**那么** 注释应变为 `/// 文档说明`。
3. **给定** 一个包含英文块注释 `/* Block comment */` 的 Rust 文件，**当** 执行“翻译为中文”操作时，**那么** 注释应变为 `/* 块注释 */`。

---

### 用户故事 2 - 翻译 Rust 代码中的中文注释为英文 (优先级: P1)

作为一名 Rust 开发者，我希望将我代码中的中文注释翻译成英文，以便我可以将代码发布到开源社区或与国际团队协作。

**优先级原因**: 核心功能需求，支持代码的国际化分享。

**独立测试**: 可以通过创建一个包含中文注释的 `.rs` 文件，运行翻译功能，并验证注释是否被正确替换为英文来测试。

**验收场景**:

1. **给定** 一个包含中文单行注释 `// 这是一个测试` 的 Rust 文件，**当** 执行“翻译为英文”操作时，**那么** 注释应变为 `// This is a test`。

---

### 边界情况

- **字符串中的类注释字符**: 当 Rust 文件中包含字符串字面量里看起来像注释的字符（如 `let s = "// not a comment";`）时，系统必须忽略该字符串内的内容，不进行翻译。
- **嵌套块注释**: Rust 支持嵌套块注释（`/* level 1 /* level 2 */ */`），系统应能正确识别整体块注释范围。
- **空注释或特殊字符**: 当注释内容为空或仅包含特殊符号（如 `// -----`）时，系统应跳过翻译或保持原样。

## 需求 *(必填)*

### 功能需求

- **FR-001**: 系统必须能够识别 IntelliJ IDE 上下文中的 Rust 源代码文件（`.rs`）。
- **FR-002**: 系统必须解析并提取 Rust 的单行注释 (`//`)。
- **FR-003**: 系统必须解析并提取 Rust 的外部文档注释 (`///`) 和内部文档注释 (`//!`)。
- **FR-004**: 系统必须解析并提取 Rust 的块注释 (`/* ... */`)。
- **FR-005**: 系统必须利用现有的翻译基础设施，将提取的注释文本在中文和英文之间进行转换。
- **FR-006**: 系统必须将翻译后的文本替换回源代码中对应的位置，保持原有的注释标记（如 `///`）和缩进格式。
- **FR-007**: 系统必须确保替换过程不破坏代码的语法结构（例如不意外修改字符串字面量）。

### 非功能需求

- **NFR-001**: 单元测试覆盖率必须 ≥ 60%。
- **NFR-002**: 实现必须符合 JetBrains 插件开发规范（如使用 PSI 进行代码解析）。
- **NFR-003**: 翻译操作的响应速度应与现有 Golang 实现相当。

### 关键实体

- **RustPsiExtractor**: 负责利用 IDE 的 PSI (Program Structure Interface) 识别和提取 Rust 注释元素。
- **CommentElement**: 通用实体，代表一个注释节点，包含文本、类型（单行/文档/块）和范围。

## 成功标准 *(必填)*

### 可衡量的结果

- **SC-001**: 功能能够正确识别并翻译 Rust 源代码中 100% 的有效注释类型（单行、文档、块）。
- **SC-002**: 经过翻译替换后的 Rust 代码能够成功通过 `cargo check` 或 IDE 的语法检查（无语法错误）。
- **SC-003**: 字符串字面量内的类注释模式在翻译过程中 100% 被忽略，未被修改。
