**功能分支**: `001-jetbrains-comment-i18n-display`
**创建时间**: 2025-12-16
**状态**: 草稿
**输入**: 用户描述: "请先读取../codei18n/readme.md和../codei18n/specs下的文档，对整个项目有个了解，就明白当前项目的需求了，我们要建一个JetBrains IDE的插件，能够支持在展示源码的时候，其中的注释被展示为对应的中文注释。"

## 用户场景与测试 *(必填)*

### 用户故事 1 - 实时替换显示翻译注释 (优先级: P1)

作为 JetBrains IDE 用户，我希望在打开 Go 源代码文件时，IDE 能够自动将英文注释替换显示为对应的中文翻译，鼠标悬停时显示英文原文，以便我能够直接阅读中文注释理解代码含义，同时在需要时可以查看原始英文注释。

**优先级原因**: 这是插件的核心价值所在。开发者打开 IDE 的主要目的就是阅读和理解代码，直接显示中文翻译比在注释下方显示更加直观和自然，不会增加视觉负担。这是 MVP 的基础功能，没有它插件就失去了存在的意义。

**独立测试**: 可以通过打开一个包含英文注释的 Go 文件，验证 IDE 编辑器中英文注释是否被中文翻译替换显示。鼠标悬停在注释上时，应显示英文原文。检查翻译内容是否正确对应原注释。

**验收场景**:

1. **给定** 用户已安装插件并打开包含英文注释的 Go 文件，**当** IDE 编辑器加载完成，**那么** 每条英文注释被替换显示为对应的中文翻译（如果映射存在），源文件本身不被修改
2. **给定** 注释的翻译映射不存在，**当** IDE 加载文件，**那么** 该注释保持显示英文原文
3. **给定** 用户鼠标悬停在已翻译的注释上，**当** 悬停超过 500ms，**那么** 显示工具提示窗口展示英文原文
4. **给定** 用户正在编辑代码，**当** 滚动查看不同部分的注释，**那么** 翻译显示实时更新，不出现延迟或闪烁
5. **给定** 文件包含大量注释（>100 条），**当** 打开文件，**那么** 所有翻译在 1 秒内完成渲染
6. **给定** 用户点击或展开已折叠的注释，**当** 展开操作完成，**那么** 显示英文原文，可以再次折叠回中文翻译

### 用户故事 2 - 插件设置与语言切换 (优先级: P1)

作为用户，我希望能够通过 IDE 设置界面配置插件的行为，包括启用/禁用翻译显示、选择目标语言、设置 codei18n CLI 路径等，以便根据个人需求定制插件功能。

**优先级原因**: 不同用户有不同的需求和环境配置。有些用户可能不需要翻译显示，有些用户的 codei18n CLI 安装在非标准路径。设置界面是保证插件可用性和灵活性的关键。

**独立测试**: 可以通过打开 IDE 设置界面，找到插件配置页面，修改各项设置（如禁用翻译显示），保存后验证设置是否生效（如注释翻译不再显示）。

**验收场景**:

1. **给定** 用户打开 IDE 设置，**当** 导航到插件配置页面，**那么** 看到插件的所有可配置选项（启用状态、目标语言、CLI 路径等）
2. **给定** 用户禁用翻译显示功能，**当** 保存设置并重新打开文件，**那么** 注释翻译不再显示
3. **给定** 用户选择目标语言为"日语"（如果支持），**当** 保存设置并重新加载，**那么** 显示日语翻译（如果映射存在）
4. **给定** codei18n CLI 不在系统 PATH 中，**当** 用户手动指定 CLI 可执行文件路径，**那么** 插件能够成功调用 CLI 并获取翻译数据
5. **给定** 设置界面的 CLI 路径输入框，**当** 用户点击浏览按钮，**那么** 弹出文件选择对话框，选择可执行文件后路径自动填充

### 用户故事 3 - codei18n CLI 集成与错误处理 (优先级: P1)

作为用户，我希望插件能够自动检测并调用 codei18n CLI 工具获取注释翻译数据，并在 CLI 不可用或出现错误时提供清晰的提示和解决方案，以便我能够顺利使用插件功能。

**优先级原因**: 插件依赖 codei18n CLI 作为后端。如果 CLI 集成不稳定或错误处理不当，插件将无法正常工作。这是插件可靠性的基础。

**独立测试**: 可以通过卸载或移动 codei18n CLI，打开 IDE 验证插件是否显示"CLI 未找到"的错误提示。安装 CLI 后，插件应自动恢复正常工作。

**验收场景**:

1. **给定** codei18n CLI 已安装且在系统 PATH 中，**当** 用户打开文件，**那么** 插件能够自动调用 CLI 获取翻译数据
2. **给定** codei18n CLI 不可用（未安装或路径错误），**当** 用户打开文件，**那么** IDE 显示通知提示"CodeI18n CLI 未找到，请安装或配置路径"，并提供设置链接
3. **给定** CLI 执行超时（>5 秒），**当** 插件调用 CLI，**那么** 放弃本次调用并记录警告日志，不阻塞 IDE 界面
4. **给定** CLI 返回错误（如映射文件损坏），**当** 插件解析响应，**那么** 显示错误通知，提示用户检查 .codei18n 配置
5. **给定** 项目根目录没有 .codei18n 配置，**当** 打开文件，**那么** 插件提示"未初始化 CodeI18n 项目，请运行 codei18n init"

### 用户故事 4 - 显示模式与用户体验优化 (优先级: P2)

作为用户，我希望能够选择注释翻译的显示方式（如替换显示、Inlay Hint、工具提示等），并且显示效果不干扰正常的代码阅读和编辑，以便获得最佳的使用体验。

**优先级原因**: 显示方式直接影响用户体验。不同用户有不同的偏好，有些用户喜欢替换显示，有些用户可能更喜欢在注释下方显示翻译。提供选择能够提升满意度。

**独立测试**: 可以通过在设置中切换显示模式（如从替换显示切换到 Inlay Hint），重新打开文件验证显示效果是否按预期变化。

**验收场景**:

1. **给定** 用户选择"替换显示"模式（默认），**当** 打开文件，**那么** 英文注释被中文翻译替换显示，鼠标悬停时显示英文原文
2. **给定** 用户选择"Inlay Hint"显示模式，**当** 打开文件，**那么** 翻译以灰色小字显示在注释下方，样式与 IDE 原生 Inlay Hint 一致
3. **给定** 用户选择"Tooltip"模式，**当** 鼠标悬停在注释上，**那么** 显示包含翻译的工具提示窗口，注释本身保持英文
4. **给定** 用户选择"Gutter Icon"模式，**当** 打开文件，**那么** 在有翻译的注释行号旁显示图标，点击图标显示翻译
5. **给定** 翻译文本较长（>100 字符），**当** 显示翻译，**那么** 自动折行或截断，不超出编辑器可视区域
6. **给定** 用户正在编辑代码，**当** 光标移动或输入文字，**那么** 翻译显示不闪烁、不抖动、不影响输入性能

### 用户故事 5 - 支持多 IDE 和版本兼容 (优先级: P2)

作为不同 JetBrains IDE 的用户（IntelliJ IDEA、GoLand、RustRover 等），我希望插件能够在我使用的 IDE 中正常工作，并且支持合理范围的 IDE 版本，以便我不必因为 IDE 选择或版本而无法使用插件。

**优先级原因**: JetBrains 平台统一，但不同 IDE 可能有细微差异。确保多 IDE 兼容性能够扩大用户群体。版本兼容性保证用户不必频繁升级 IDE。

**独立测试**: 可以在不同 IDE（如 IntelliJ IDEA 2023.3、GoLand 2024.1）中安装插件，打开相同的 Go 文件，验证功能是否一致。

**验收场景**:

1. **给定** 用户使用 GoLand 2023.3+，**当** 安装并启用插件，**那么** 所有功能正常工作
2. **给定** 用户使用 IntelliJ IDEA Ultimate 2023.3+，**当** 安装插件，**那么** 插件能够识别 Go 文件并显示翻译
3. **给定** 用户使用低于最低支持版本的 IDE（如 2022.2），**当** 尝试安装插件，**那么** IDE 阻止安装并提示"需要 IDE 版本 2023.3 或更高"
4. **给定** 插件在 plugin.xml 中声明支持的 IDE 列表，**当** 用户在非 Go 项目中使用（如纯 Java 项目），**那么** 插件不激活或提示"仅支持 Go 项目"

### 用户故事 6 - 翻译缓存与性能优化 (优先级: P3)

作为频繁打开大型文件的用户，我希望插件能够缓存已获取的翻译数据，避免重复调用 CLI，以便提升响应速度和减少资源消耗。

**优先级原因**: 性能优化是锦上添花，但不是 MVP 必需。在基本功能稳定后，缓存能够显著提升用户体验。

**独立测试**: 可以通过打开同一文件多次，第一次加载后观察日志，后续打开应使用缓存而非再次调用 CLI。

**验收场景**:

1. **给定** 用户第一次打开文件，**当** 插件调用 CLI 获取翻译，**那么** 将结果缓存到内存
2. **给定** 用户关闭并重新打开同一文件，**当** 插件需要翻译数据，**那么** 从缓存读取，响应时间 < 50ms
3. **给定** 映射文件已更新（如用户运行了 codei18n translate），**当** 插件检测到文件变化，**那么** 自动清除缓存并重新加载
4. **给定** 缓存占用内存超过阈值（如 50MB），**当** 继续打开新文件，**那么** 采用 LRU 策略淘汰旧缓存

### 边界情况

- **大文件性能**: 当 Go 文件包含 >1000 条注释时，插件加载和渲染性能如何？应保证在 2 秒内完成。
- **并发文件打开**: 当用户同时打开多个文件时，插件如何避免并发调用 CLI 导致性能问题？应限制并发数或使用队列。
- **CLI 版本不兼容**: 当用户安装的 codei18n CLI 版本过低或过高不兼容时，插件如何检测并提示？
- **源码实时编辑**: 当用户正在编辑注释（添加、删除、修改）时，翻译显示如何实时更新？
- **多语言项目**: 如果项目包含多种编程语言（Go + Rust），插件如何处理？MVP 阶段仅支持 Go。
- **网络隔离环境**: 在没有网络连接的环境中，插件依赖的本地 CLI 和映射文件应能正常工作。
- **权限问题**: 当 codei18n CLI 没有执行权限时，插件如何提示用户？
- **Unicode 和特殊字符**: 注释中包含 emoji、CJK 字符、特殊符号时，显示是否正常？
- **主题适配**: 插件的翻译显示样式是否适配 IDE 的明亮/暗黑主题？

## 需求 *(必填)*

### 功能需求

#### 核心显示需求

- **FR-001**: 插件必须能够解析 IDE 打开的 Go 源代码文件，识别所有注释位置（行注释、块注释、文档注释）
- **FR-002**: 插件必须调用 codei18n CLI 工具获取注释的翻译数据（通过 `codei18n scan --file <path> --with-translations --lang zh-CN --format json`）
- **FR-003**: 插件必须以替换显示方式将英文注释替换为中文翻译（默认模式），源文件本身不被修改
- **FR-004**: 插件必须支持通过代码折叠（Folding）机制实现注释的替换显示，用户可以展开查看原文或折叠显示翻译
- **FR-005**: 插件必须支持在编辑器中实时更新翻译显示，当用户滚动或编辑时不出现卡顿

#### CLI 集成需求

- **FR-006**: 插件必须能够检测 codei18n CLI 是否可用（检查 PATH 或用户配置的路径）
- **FR-007**: 插件必须通过子进程调用 CLI，并正确处理 stdin/stdout/stderr
- **FR-008**: 插件必须解析 CLI 返回的 JSON 格式数据，提取注释 ID、位置、翻译文本
- **FR-009**: 插件必须设置 CLI 调用超时（默认 5 秒），超时后放弃本次调用
- **FR-010**: 插件必须在 CLI 不可用时显示友好的错误通知，提供解决方案链接

#### 配置管理需求

- **FR-011**: 插件必须提供设置界面（Settings/Preferences > Tools > CodeI18n）
- **FR-012**: 设置界面必须包含以下配置项：
  - 启用/禁用翻译显示（默认启用）
  - 目标语言选择（默认 zh-CN）
  - codei18n CLI 可执行文件路径（默认从 PATH 查找）
  - 显示模式选择（替换显示 / Inlay Hint / Tooltip / Gutter Icon，默认替换显示）
  - 鼠标悬停显示原文（默认启用，仅在替换显示模式下生效）
- **FR-013**: 插件必须将用户配置持久化到 IDE 的配置文件中
- **FR-014**: 插件必须在配置变更后立即应用新设置，无需重启 IDE

#### 错误处理需求

- **FR-015**: 插件必须在以下情况显示通知：
  - CLI 未找到或不可执行
  - CLI 执行超时
  - CLI 返回错误信息
  - 项目未初始化 CodeI18n（缺少 .codei18n 目录）
- **FR-016**: 所有错误通知必须提供操作建议（如"打开设置"、"查看文档"）
- **FR-017**: 插件必须记录详细日志到 IDE 日志文件，便于问题排查

#### 性能需求

- **FR-018**: 插件必须在文件打开后 1 秒内完成翻译数据的加载和显示（小于 100 条注释）
- **FR-019**: 插件必须实现翻译数据的内存缓存，避免重复调用 CLI
- **FR-020**: 插件必须在后台线程执行 CLI 调用，不阻塞 IDE UI 线程

#### 兼容性需求

- **FR-021**: 插件必须支持 IntelliJ IDEA Ultimate 2023.3 及以上版本
- **FR-022**: 插件必须支持 GoLand 2023.3 及以上版本
- **FR-023**: 插件必须在 plugin.xml 中声明最低和最高 IDE 版本
- **FR-024**: 插件必须仅在打开 Go 语言文件时激活翻译显示功能

### 非功能需求

- **NFR-001**: 单元测试覆盖率必须 ≥ 60% (章程要求, 不可协商)
- **NFR-002**: 必须符合 JetBrains 插件开发规范
- **NFR-003**: 必须符合 Java 业界规范和代码风格
- **NFR-004**: 插件打包大小必须 < 5MB
- **NFR-005**: 插件启动时间（从 IDE 启动到插件就绪）必须 < 500ms
- **NFR-006**: 翻译显示不得影响代码编辑的响应速度（输入延迟 < 10ms）
- **NFR-007**: 插件必须适配 IDE 的明亮和暗黑主题

### 关键实体

- **TranslatedComment（翻译注释）**: 表示一条注释及其翻译，包含属性：
  - `commentId` (String): 注释的唯一标识符（由 CLI 提供）
  - `originalText` (String): 原始注释文本（英文）
  - `translatedText` (String): 翻译后的文本（中文）
  - `startOffset` (int): 注释在文件中的起始偏移量
  - `endOffset` (int): 注释在文件中的结束偏移量
  - `lineNumber` (int): 注释所在行号

- **CliConfiguration（CLI 配置）**: 表示 codei18n CLI 的配置信息，包含属性：
  - `cliPath` (String): CLI 可执行文件的路径
  - `targetLanguage` (String): 目标翻译语言代码（如 "zh-CN"）
  - `timeout` (int): CLI 调用超时时间（毫秒）

- **PluginSettings（插件设置）**: 表示插件的用户配置，包含属性：
  - `enabled` (boolean): 是否启用翻译显示
  - `displayMode` (DisplayMode): 显示模式（INLAY_HINT, TOOLTIP, GUTTER_ICON）
  - `cliConfiguration` (CliConfiguration): CLI 配置
  - `cacheEnabled` (boolean): 是否启用缓存

- **TranslationCache（翻译缓存）**: 表示翻译数据的缓存，包含属性：
  - `filePath` (String): 文件路径
  - `translations` (List<TranslatedComment>): 翻译列表
  - `timestamp` (long): 缓存时间戳
  - `mappingFileHash` (String): 映射文件的哈希值（用于检测变更）

## 假设与约束

### 假设

1. **IDE 版本**: 假设用户使用 IntelliJ IDEA 或 GoLand 2023.3 及以上版本
2. **codei18n CLI 可用**: 假设用户已安装 codei18n CLI 工具（v0.1.0+）并配置正确
3. **Go 语言支持**: 假设用户的 IDE 已安装 Go 语言插件
4. **项目已初始化**: 假设用户的 Go 项目已运行 `codei18n init` 并生成了 `.codei18n` 配置
5. **映射文件存在**: 假设项目中存在注释的翻译映射文件（`.codei18n/mappings.json`）
6. **文件编码**: 假设所有源文件使用 UTF-8 编码
7. **操作系统**: 假设插件在 Windows、macOS、Linux 三大平台运行

### 约束

1. **语言支持**: MVP 仅支持 Go 语言的注释翻译显示
2. **翻译方向**: 仅支持英文到中文的单向显示（不支持中文到英文）
3. **离线模式**: 插件本身不包含翻译引擎，完全依赖 codei18n CLI 和本地映射文件
4. **实时编辑**: 对正在编辑的注释，翻译显示可能存在短暂延迟（< 1 秒）
5. **CLI 版本**: 插件与 codei18n CLI v0.1.x 版本兼容，更高版本需验证兼容性
6. **性能限制**: 对于包含 >1000 条注释的大文件，翻译加载时间可能达到 2-3 秒
7. **UI 定制**: 翻译显示样式遵循 JetBrains UI 规范，不支持高度自定义

## 依赖关系

- IntelliJ Platform SDK 2023.3+
- JDK 17+（插件开发环境）
- codei18n CLI v0.1.0+（运行时依赖）
- Go 语言插件（IntelliJ IDEA 用户需要）
